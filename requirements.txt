# --- Core Machine Learning & Deep Learning ---
# train_*.py, mil_benchmark.py, sil_benchmark.py, quantize_int8_basic.py,
# prune_model.py, hil_benchmark.py (SIL/MIL cross-run). The scripts use
# tf.keras (Keras 3 ships with TensorFlow >= 2.16; no separate `keras` entry).
# Floor 2.16 because the models rely on Keras 3; the verified build is 2.21.
tensorflow>=2.16.0

# --- Image Processing & Datasets ---
# process_images.py, reshape_images.py, hil_benchmark.py (stimulus
# window, frame handling)
opencv-python>=4.8.0
# images.py, the one image loader of training, calibration, MIL, SIL and the
# PIL bench; calibrate_hil_rig.py (text of the live preview)
pillow>=10.0.0
# Floor 2.0: the opencv-python and tensorflow wheels of the verified stack are
# built against the numpy 2.x ABI; importing them with numpy 1.x fails.
numpy>=2.0.0

# --- Evaluation metrics (REQUIRED for every MIL/SIL/PIL/HIL result) ---
# accuracy, precision/recall/F1 and the confusion matrix in mil_benchmark.py,
# sil_benchmark.py, pil_benchmark.py and hil_benchmark.py.
# mil_benchmark.py and sil_benchmark.py EXIT if these two are missing; the PIL
# and HIL benches run but then write no metrics_*.json nor confusion matrix.
# Note: they are imported inside try/except, so a bare `python script.py`
# does not fail at import time; the lack only shows at the end of the run.
scikit-learn>=1.3.0
# Confusion-matrix heatmaps in the same four scripts.
seaborn>=0.12.0
# Exact tests (binomtest, fisher_exact) and the t distribution in
# build_ladder_tables.py. Floor 1.13: first release built for the numpy 2.x ABI.
scipy>=1.13.0

# --- Hardware Interface & Communication ---
# Serial protocol with the board: pil_benchmark.py, hil_benchmark.py
pyserial>=3.5

# --- Visualization ---
# Training curves and confusion matrices (train_*.py, evaluation.py, the board benches)
matplotlib>=3.7.0
# keras.callbacks.TensorBoard in train_mobilenet.py, train_resnet.py and
# train_squeezenet.py (also installed as a TensorFlow dependency)
tensorboard>=2.15.0
