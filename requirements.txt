# --- Core Machine Learning & Deep Learning ---
# train_*.py, test_model.py, test_tflite_model.py, quantize_int8_basic.py,
# prune_model.py, hil_camera_benchmark.py (SIL/MIL cross-run). The scripts use
# tf.keras (Keras 3 ships with TensorFlow >= 2.16; no separate `keras` entry).
# Floor 2.16 because the models rely on Keras 3; the verified build is 2.21.
tensorflow>=2.16.0

# --- Image Processing & Datasets ---
# process_images.py, reshape_images.py, hil_camera_benchmark.py (stimulus
# window, frame handling)
opencv-python>=4.8.0
# pil_benchmark.py (image loading / resize before the serial transfer)
pillow>=10.0.0
# Floor 2.0: the opencv-python and tensorflow wheels of the verified stack are
# built against the numpy 2.x ABI; importing them with numpy 1.x fails.
numpy>=2.0.0

# --- Evaluation metrics (REQUIRED for every MIL/SIL/PIL/HIL result) ---
# accuracy, precision/recall/F1 and the confusion matrix in test_model.py,
# test_tflite_model.py, pil_benchmark.py and hil_camera_benchmark.py.
# test_model.py and test_tflite_model.py EXIT if these two are missing; the PIL
# and HIL benches run but then write no metrics_*.json nor confusion matrix.
# Note: they are imported inside try/except, so a bare `python script.py`
# does not fail at import time; the lack only shows at the end of the run.
scikit-learn>=1.3.0
# Confusion-matrix heatmaps in the same four scripts.
seaborn>=0.12.0

# --- Hardware Interface & Communication ---
# Serial protocol with the board: pil_benchmark.py, hil_camera_benchmark.py
pyserial>=3.5

# --- Visualization ---
# Training curves and confusion matrices (train_*.py, test_*.py, benches)
matplotlib>=3.7.0
